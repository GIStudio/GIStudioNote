# NSFC 申请资格与申报流程

一次正式申请需要同时满足人的资格、项目范围、依托单位要求和材料规则。先确认这些条件，再投入完整申请书的写作，可以避免因资格或程序问题而无法受理。

依托单位是向基金委注册、承担项目申报和管理责任的单位，通常是申请人所在的高校或科研机构。个人账号负责填报材料，单位科研管理部门负责相应审核与提交；不能把正式申报理解为个人独立寄出一份申请书。[2026 年申请通告](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

本页使用 2026 年规则。该年度集中接收时间为 3 月 1 日至 3 月 20 日 16 时，已经结束；非集中接收项目按各自指南办理。未来年度的日期不能直接照搬。[基金委申请时间说明](https://www.nsfc.gov.cn/p1/2961/2962/2967/sqsj.html)

## 先核查自己的身份

一般条件包括从事基础研究的经历，并满足高级专业技术职务、博士学位、两名同领域高级专业技术职务人员推荐中的一项条件。各类项目还有特殊要求，推荐信也不能替代研究生身份等其他资格限制。[2026 年申请规定](https://www.nsfc.gov.cn/p1/2931/3971/3974/sqgd2.html)

| 身份或情形 | 需要怎样判断 |
| --- | --- |
| 普通全日制在读博士生 | 截止时尚未获得学位，通常不能作为常规项目申请人；单独核查学生试点渠道 |
| 在职攻读研究生学位 | 满足相应条件并经导师同意，可通过受聘依托单位申请规定允许的项目；港澳依托单位不适用这一例外 |
| 已获博士学位的研究者 | 继续核查聘用关系、项目年龄和限项等，博士学位本身不等于满足全部条件 |
| 在站博士后 | 可申请部分项目，但港澳依托单位青年 C 类等有额外限制 |
| 无工作单位或单位不是依托单位 | 对规定允许的项目，核查能否取得依托单位同意并签订书面合同；在职研究生不能直接套用这一渠道 |

上述边界见[基金委申请条件问答](https://www.nsfc.gov.cn/p1/2961/2962/3643/tj.html)。身份复杂时，向拟申报单位科研管理部门提供真实的学位、聘用和在读情况，请其依据当年指南确认。

青年 C 类在 2026 年适用的年龄条件为申请当年 1 月 1 日男性未满 35 周岁、女性未满 40 周岁，研究期限为 3 年。正式申请还需核查曾获资助情况和其他条件。[青年 C 类管理办法](https://www.nsfc.gov.cn/p1/2871/2874/2882/136725.html)

## 选择项目、学科和研究属性

先读项目类型的资助定位，再读相关科学部的资助领域与注意事项。自主选题项目和明确给出方向的指南项目，准备方式不同。联合基金等还需逐项检查具体指南需求。

申请代码是基金委划分学科和研究领域的编码，会影响申请归属与评审组织。选择时应以主要科学问题为依据。采用一种 AI 方法，不会自动使项目属于信息科学；研究城市也不会自动使项目属于某一个科学部。判断主要知识贡献是什么、希望由什么学术共同体评价，再核对官方代码和学科要求。部分科学部要求代码选择到指定层级。[基金委申请书与代码问答](https://www.nsfc.gov.cn/p1/2961/2962/3642/sqs.html)

研究属性同样按研究内容选择。自由探索类由好奇心和学术灵感驱动，目标导向类由经济社会或国家需求牵引，不应为迎合想象中的评审偏好随意更改。[2026 年申请通告](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

## 通过依托单位完成申报

1. 向单位科研管理部门确认资格、校内截止日期和项目限项，申请信息系统账号。
2. 从信息系统取得当年该类项目的填报说明和正文提纲，核对项目类型、代码、研究方向和研究属性。
3. 准备正文、个人简历、成果及其个人贡献说明，按要求完成参与者和合作单位材料。
4. 根据项目实际情况准备导师同意、伦理审查、推荐或其他证明，交单位审核。
5. 查看系统生成的最终申请书，检查正文、附件、项目信息和引用是否一致。
6. 在校内时限前提交，确认依托单位完成审核和正式提交，并保存最终版本与状态记录。

申请人完成上传以后，仍需依托单位按规定确认提交。校内时限可能早于基金委截止时间，应以单位通知安排留出修改时间。[2026 年申请通告](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

## 经费与限项要一起核对

2026 年青年科学基金 A、B、C 类及试点青年学生基础研究项目实行包干制，申请时无需编制预算；其余项目按规定实行预算制。这里的包干制是经费管理方式，资金使用仍需遵守管理和单位实施办法。预算制项目则需按研究任务说明经费需求，避免为了凑总额列支。[2026 年资金安排](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

限项会受到项目类别、职称、在研情况、参与身份和历史资助等影响，不能概括成“每人最多两项”。管理科学部与国家社科基金还有相关限制，需逐项核对。[基金委限项规定](https://www.nsfc.gov.cn/p1/2961/2962/3644/xx.html)

## 提交前如何自查

- 资格依据来自当年指南，单位已确认申报路径。
- 项目类别、代码、研究属性、期限与当前系统要求一致。
- 合作者已确认分工与材料，所需证明齐全。
- 已完成的结果与计划开展的工作分别表述，引用可以回到原始来源。
- 最终生成文件包含完整正文和附件，系统显示单位已完成所需提交。

初审主要解决是否受理，同行评审解决是否资助。未获资助后，可将反馈分为科学问题、研究设计、前期基础和表达问题，再逐项修订；不要仅凭一条意见推断全部评审原因。
