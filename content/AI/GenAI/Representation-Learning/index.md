读到 `by the river bank`，下一段可能讲泥地或水位；读到 `approved by the bank`，接下来谈的可能是贷款。两处 `bank` 拼写相同。如果分词器给它们同一个编号，模型查到的起始向量也一样。真正有趣的是下一步：**同一行向量，怎样在两段话里变成两个不同的计算结果？** 沿着这个词走到模型输出，就能看清表征在哪里产生、它为何会对某个任务有用，以及换任务时需要改什么。

## 表征把哪些关系交给后续计算

**表征**是对象经过编码后得到的形式；**表征学习**是利用数据和训练目标学到一种编码方式。一个句子可以由词元编号、向量序列或一个汇总向量表示；一张图片可以用像素、特征张量或其他结构表示。讨论神经网络时，通常关心的是某一层交给下一步计算的数值。

先用两盏灯看清编码的作用。灭记为 0，亮记为 1，原始记录 $(x_1,x_2)$ 分别保留两盏灯的状态。要判断「是不是恰好亮一盏」，可以先算 $z=|x_1-x_2|$。此后只看 $z$：等于 1 就是恰好亮一盏。单看 $z$ 无法还原亮的是哪一盏；如果把表征写成 $(x_1,z)$，则能用 $x_2=|x_1-z|$ 找回灯 2，同时依然可以直接从第二个坐标读出答案。这是教学构造。它说明，同样保留全部输入信息，两种写法也可能让某项判断变得难易不同。

神经网络把手写的变换换成可训练函数。设 $x$ 是输入，$f_\theta$ 是带参数 $\theta$ 的编码函数，$z=f_\theta(x)$ 是它为这一条输入算出的表征；另一个函数 $g_\phi$ 用参数 $\phi$ 把 $z$ 读成预测 $\hat y$。架构规定算哪些步骤，训练改变参数，而每次前向计算根据当前输入产生新的中间值。早期反向传播研究已经展示过，隐藏单元可以随任务损失的优化学到有用区分。[@rumelhartLearningRepresentations1986]

## 从分词到查表，才有模型的起始向量

回到 `bank`。分词器把文本变成词元（token）序列，再把词元映射到词表编号。假设 `river`、`bank`、`loan` 在教学词表中分别是 0、1、2。`river bank` 会变成 $[0,1]$。编号只指向词表的一项；即使 BPE 建词表时使用语料频次，编号之间的数值距离也没有频率或语义含义。真实分词器可能把空格或词边界编码进词元，因此比较两处词的向量之前，要先确认它们的 ID 确实相同。[@sennrichNeuralMachineTranslation2016]

设嵌入表 $E$ 有 $V$ 行、$d$ 列：$V$ 是词表大小，$d$ 是每条向量的宽度。输入 ID 为 1 时，模型取编号为 1 的那一行。若它是 $(-0.3,0.9)$，两处相同 ID 就都从这两个数出发。训练可以改变这一行；冻结表后，未来再输入这个 ID，仍会读到冻结时保存的数值。这里的浮点数是可参与模型计算的坐标，向量坐标是否适合某种相似度比较，要看训练目标和测试结果。

Word2Vec 的经典词向量也为同一个词储存固定坐标。以 SGNS 为例，它根据语料中的词与上下文关系学习向量。另一条路线先统计共现，再显式分解词与上下文的矩阵；在特定假设下，SGNS 则可从隐式分解移位的点互信息矩阵来理解。这些路线都能得到静态词向量。Transformer 会在查表之后再为**每次出现**的这个词计算新的向量。图像也可以从像素算出向量，或者量化为学习得到的离散码；具体做法见[[AI/GenAI/Representation-Learning/tokenization-and-embeddings|分词、嵌入与上下文]]。[@mikolovDistributedRepresentations2013; @levyImplicitMatrixFactorization2014]

## 隐藏状态就是某一层、某一位置算出来的一列数

在仅解码器的 Transformer 中，设输入有 $T$ 个词元，每个位置有 $d$ 个数。关注最后一个位置 $t=T$，也就是这段前缀末尾的 `bank`。记 $h_t^{(\ell)}$ 为**第 $\ell$ 个模型块计算完毕后，位置 $t$ 的 $d$ 维向量**。同一个符号里，上标数层，下标数序列位置。它是当前输入产生的激活；模型权重固定时，不同的输入依然会算出不同的激活。

```text
原始文本
  → 分词和编号：ID 序列 [T]
  → 嵌入查表：每个位置一个起始向量 [T, d]
  → 第 1 个 Transformer 块：带因果掩码的注意力与逐位置变换 [T, d]
  → … → 第 L 个块的输出 [T, d]
  → ★ 取位置 t 的最后层向量 h_t^(L) [d]
  → 词表输出头：logits [V]
  → softmax：下一个词元的概率 [V]
  → 选出一个词元 ID [标量]，接到序列末尾，再预测下一项
```

模型会在计算中引入位置关系。在允许相加的绝对位置设计中，可以先把位置向量加到输入嵌入上；像 [[AI/LLM/transformer-positional-encoding|RoPE]] 这样的方案则在注意力内处理位置。计算某层时，$h_t^{(\ell)}$ 依赖上一层同一位置的值，也可以经自注意力读取上一层的其他可见位置；其输入并非只有前一层的 $h_t^{(\ell-1)}$。因果掩码把可见范围限制在当前位置和左侧，所以 `by the river bank` 中的 `river` 可以影响 `bank`；若输入是 `bank loan`，要用右侧的 `loan`，就得在已读到 `loan` 的位置读出，或改用双向编码器。[@vaswaniAttentionAllNeed2017; @devlinBert2019]

一个块里的**注意力头**负责计算各位置如何汇入其他位置的信息，多个头的结果合起来交给后续层。词表**输出头**在表示算完之后负责读出，名字都叫「头」，在计算图里的位置不同。上图为便于跟踪省略了末端归一化等实现细节；取给输出头的向量时，应以具体模型为准。[@vaswaniAttentionAllNeed2017; @radfordLanguageModelsUnsupervised2019]

## 词表位置是编号，里面的值是分数

把位置 $t$ 的末端向量简记为列向量 $h_t$。输出头用 $V\times d$ 的矩阵 $W_o$ 做投影，偏置 $b$ 可选。计算分数和概率的两个步骤是：

$$
z_t=W_oh_t+b,\qquad
p_{t,j}=\frac{\exp(z_{t,j})}{\sum_{k=0}^{V-1}\exp(z_{t,k})}.
$$

$z_t$ 有 $V$ 个分量，每项叫一个 logit，也就是归一化之前的分数。按通常与词表对齐的零起始索引，$z_{t,j}$ 是「下一个词元为 ID $j$」的分数，而 $p_{t,j}$ 是对应概率。假设三项分数为 $[0,\ln 2,\ln 3]$，概率就是 $[1/6,1/3,1/2]$。贪心解码取最大项的**索引 2**，再把 ID 2 查回词元；$\ln 3$ 和 $1/2$ 都是该位置的**值**。softmax 保持分数的排序，所以对分数和对概率做 argmax，会得到同一组最大值索引；遇到并列时还需约定取哪一个。[@vaswaniAttentionAllNeed2017]

按概率采样也会得到一个词元 ID，只是不总选最高分。无论使用哪种选择规则，这一步都在输出头之后。选出的 ID 会作为下一步输入；前文仍是上下文，推理时可用缓存避免重复计算。一个位置的完整词表概率有 $V$ 项；二分类可以只用一个正类概率，因为另一项等于 1 减去它。概率向量表达了**这一次预测**，隐藏向量则还可以交给别的任务头做检验。

## 训练让整个计算链为同一个目标调整

下一词元训练用真实文本里的下一项作为目标。刚才的三项概率中，若正确答案是 ID 2，这个位置的交叉熵就是 $-\ln(1/2)=\ln 2$。训练时往往可以在同一条真实序列的多个位置并行计算损失；生成时才逐步选择词元并接回前缀。这个差别很重要：训练的梯度来自目标词元与分数之间的损失，无需穿过推理时的 argmax。[@radfordLanguageModelsUnsupervised2019] [[DL/likelihood-nll-and-cross-entropy|交叉熵推导]]。

这里说「端到端」，要先指明两端。对下一词元训练，可训练链从**词元编号进入嵌入查询**开始，到**输出头给词表打分并和真实下一项计算损失**为止。若嵌入表、各个 Transformer 块和头都参与优化，损失的梯度就可以共同更新它们。固定分词规则虽然在整个文本处理流程中，却不在这一条梯度链里。使用另一个目标时，两端也会变：例如分类读到类别损失，自编码器则把输入编码后再重建。这就是为什么表征学习既可以从嵌入层开始，也可以发生在像素投影或其他输入变换中。[@rumelhartLearningRepresentations1986; @vaswaniAttentionAllNeed2017; @rombachLatentDiffusion2022]

训练的读出也可以专为一个训练目标设置。例如 SimCLR 给同一张照片做两次增强，在投影空间里拉高这两个视图相对于其他视图的相似度。训练后保留编码器，并用编码器输出评估分类。这说明，看到一个供下游使用的向量，还可以追问：训练时哪一种目标塑造了它，测下游时又从哪里把它取出来？[@chenSimclr2020]

反向传播按链式法则计算损失对中间值和参数的敏感程度，优化器再按配置更新可训练参数。还有一种常见设计叫**权重绑定**（weight tying）：输入查表和词表输出都使用同一个矩阵 $E$。查表选一行；词表输出把末端隐藏向量和每一行做点积。两处使用对同一参数产生两路梯度贡献，最后相加。输入一路直接用到本批次查过的行；常规全词表 softmax 的输出一路还可能给本次没查到的行提供梯度。两路的形状相同，数值不要求相同。[[AI/GenAI/Representation-Learning/tied-embeddings-and-gradients|权重绑定的双路径梯度]]用两个词元把这一步完整算出来。[@pressUsingOutputEmbedding2017; @vaswaniAttentionAllNeed2017]

## 换一个头，怎样判断旧表征还有用

现在换一道题。给定时刻 $t$ 的向量，让模型判断 `bank` 表示「河岸」还是「银行」。取向量的位置可以沿用上面的例子，但新分类头输出的是两个类别的分数，输出坐标不再是词表。如果改做回归，头可以直接返回一个数，后处理也随任务改变。换头换的是**从表征到答案的读法**；冻结并以相同方式运行主干时，同一输入的主干表征保持不变。

先固定主干，只训练一个线性分类器，这是一种**线性探测**。成功说明：对所选层、位置和测试样本，这项信息能被这种读出规则利用。要让结论站得住，可以在同一数据划分上对比静态嵌入和几层隐藏状态，使用同样的读出器，检查它是否只靠记住训练样本中的词或模板。固定主干但使用非线性头仍可以做迁移，只是回答了另一个问题：更复杂的读出器能否利用这些特征。探针高分也不能单独说明旧词表头做预测时**真的用到了**这个信息；那需要控制干预前后的模型行为。[[AI/GenAI/Representation-Learning/probing-and-fine-tuning|探针的实验设计]]有分组、对照和算例。[@devlinBert2019; @hewittDesigningInterpretingProbes2019; @vigInvestigatingGenderBias2020]

表征的几何形状也可以提供线索。PCA 看高方差线性方向，t-SNE 或 UMAP 可以从邻域关系得到低维图。观察到分簇后，可以回到原空间计算近邻检索表现，再在留出样本上做定量读出，检查结果是不是依赖投影设置。要判断是否存在低维结构，需要另外估计维度或检验稳定性；要判断某个中间量是不是模型在用，还需干预它并观察原输出。例如一项 GPT 研究在输入受扰动后恢复指定隐藏状态，测量事实续写概率如何随之改变。证据只覆盖所检验的模型、提示和干预。[[DL/dimensionality-reduction-visualization|怎样读高维表征的降维图]]。[@vanderMaatenVisualizingData2008; @mcInnesUMAPUniformManifold2018; @mengLocatingEditingFactual2022]

只训头时，主干不更新，但「是否对它求梯度」要看计算图和训练配置。可以先离线提取向量再训练新头；也可以把主干输出接到新头前，用 `detach` 切断这一路的反向连接。反过来，如果冻结模块的**前面**还有要训练的参数，通常需要让梯度通过该模块，才能更新更早的参数。若旧头和输入表共享同一参数，训练复用这个参数的头也会改变输入表；要做严格的固定表征实验，可以保持共享表冻结，另建一个独立的新头。[PyTorch 自动求导说明](https://docs.pytorch.org/docs/stable/notes/autograd.html)。[@pressUsingOutputEmbedding2017]

## 微调让产生表征的计算也能适应新任务

只训练一个读出头，模型就只能从现有向量里寻找可用的关系。如果希望训练目标重塑这些向量，可以让主干中的部分参数参与优化；更新所有参数是全量微调。部分微调没有规定至少解冻几层，报告时写清更新了哪些矩阵或模块，比报层数更容易比较。[@devlinBert2019]

参数高效微调还可以在冻结原参数的同时，训练少量适配参数。以 LoRA 为例，某块线性投影的原始权重是 $W_0$，适配分支先用 $A$ 把输入投影到 $r$ 维，再用 $B$ 投回原投影的输出宽度，加入一项 $\Delta W=(\alpha/r)BA$。原始 $W_0$ 不更新，但经过该投影的激活会变。这里说的是**某一块**矩阵，不是把整网折成一张矩阵；挑了多块就分别加分支，由同一个任务损失联合训练。怎样按实际矩阵形状计算参数量，何时能把分支并回原权重，见[[AI/GenAI/Representation-Learning/lora-low-rank-updates|LoRA 的低秩更新]]。[@huLoRALowRankAdaptation2022]

## 生成模型把表征用在不同的地方

回到续写。语言模型每走一步，就把当前前缀的末端隐藏状态读成下一词元概率，然后把选中的词元接回输入。输出头读出的是词表分布，生成过程经过的是一串离散选择。

图像潜扩散模型则把另一种表征作为更新对象。先训练自编码器，让编码后的图像网格能被解码回图像；扩散模型接着在网格上学习如何处理噪声。纯文本生图时，从随机噪声网格出发，结合文本条件不断更新它，最后用解码器得到像素。这里至少有两个不同的数值对象：给模型提示的文本向量，以及正在被生成的图像潜网格。重建能不能留住细节、生成结果像不像真实图像、冻结编码器后能不能给新照片做分类，需要用不同的实验回答。[[AI/GenAI/Representation-Learning/representations-in-generative-models|文本续写与潜空间去噪的对照]]展开这两种模型的训练与生成。[@rombachLatentDiffusion2022]

再看最初的两个 `bank`。如果要知道模型怎样形成词义线索，就去看它在**哪个位置、哪一层**算出了什么；如果要知道模型怎样利用它，就看**谁读取了这个向量、输出是什么**。保留这两个问题，就能沿同一条思路读懂从词元、隐藏状态到潜网格的不同表征。
