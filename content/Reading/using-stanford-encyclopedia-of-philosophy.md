# 如何把 SEP 用作研究工具

[Stanford Encyclopedia of Philosophy（SEP）](https://plato.stanford.edu/)
是由领域专家撰写、编辑委员会审阅并持续更新的开放学术参考工具。它最适合
回答“这个概念有哪些竞争性定义、理论传统与关键争论”，而不是替代原始论文、
系统综述或经验数据库。

## 推荐工作流

```text
研究中出现概念歧义
-> SEP 词条：识别定义、争论、相关条目和书目
-> 原始论文 / 系统综述：核验经验发现与方法
-> 研究笔记：区分理论定位与经验支持
-> 正式写作：引用稳定归档版本或原始来源
```

## SEP 能解决什么

- 快速找到一个概念所属的哲学问题和理论传统。
- 比较同一词语下互不相容的定义或论证。
- 通过 `Related Entries` 和 bibliography 建立后续精读路线。
- 处理跨学科词语的边界，例如 trust、causation、explanation、justice、
  collective action 和 social ontology。

## SEP 不能解决什么

- 不能证明一个社会科学变量的经验效应。
- 不能替代领域内最新的系统综述或方法论文。
- 词条书目只是待阅读清单，不等于已经完成证据核验。
- 动态页面会更新；只保存活动页 URL 不足以复核历史表述。

## 引用时为什么要用归档版本

SEP 的[引用说明](https://plato.stanford.edu/cite.html)建议优先引用固定归档。
归档通常在每年 3、6、9、12 月生成，可以避免词条更新后引用对象发生变化。

至少记录：

1. 词条作者；
2. 词条标题；
3. SEP 的季节与年份版本；
4. 编辑者；
5. 对应归档 URL；
6. 实际访问或核验日期。

引用一个理论定义时，SEP 可以是合适入口；引用政策、健康、交通或行为的
经验效应时，应继续追到原始研究。

## 一张使用检查表

- [ ] 我是在澄清概念，还是在寻找经验效应？
- [ ] 词条是否呈现多个竞争性定义？
- [ ] 我是否区分了词条作者的综合与原始作者的主张？
- [ ] 书目中的关键来源是否已经实际阅读？
- [ ] 正式引用是否指向可复核的归档版本？
- [ ] 经验结论是否回到了原始论文或系统综述？
