**arm 在机器学习里通常不是芯片，而是一个可比较的分支**：要么是老虎机里可以拉的一个选项，要么是实验里一个处理组。看到它先问一句：这个分支在和谁比？

## 一、多臂老虎机：arm 是一个可选动作

多臂老虎机（multi-armed bandit）把决策问题写成：有 $K$ 个 arm，每次选一个，得到一个随机回报，目标是在有限次尝试里让累计回报尽量高。

- **arm**：一个可选动作或策略。推荐系统里可以是“推科技”“推体育”“推娱乐”三路内容。
- **拉动一次**：选择一次，观察一次回报，例如点击、停留时长或转化。
- **探索与利用**：一直选当前最好的 arm 可能错过更优选项；一直试新 arm 又浪费收益。
- **遗憾（regret）**：最优策略的期望收益减去实际收益，衡量“因为不知道而付出的代价”。

常见做法包括 ε-贪心、置信上界（UCB）和 Thompson 采样。UCB 用“均值加不确定性”给每个 arm 打分，被尝试次数少的 arm 会得到额外加分，从而被再试一次。[Auer、Cesa-Bianchi 与 Fischer 2002](https://doi.org/10.1023/A:1013689704352) 更完整的框架见 [Sutton 与 Barto 的强化学习教材](http://incompleteideas.net/book/the-book-2nd.html)。

注意 arm 是**策略**，不是用户。上下文老虎机里，同一组 arm 对不同用户的最优选择不同，但 arm 的集合没有变。

## 二、实验设计：arm 是一个实验组

做消融或对照实验时，arm 指一个配置组：baseline arm 是对照，treatment arm 是处理组。常见写法是把差异集中在一个变量上：

```python
if arm == "baseline":
    train_transform = RandomHorizontalFlip()
elif arm == "color_jitter":
    train_transform = Compose([
        RandomHorizontalFlip(),
        ColorJitter(),
    ])
```

要让这个比较成立，除了被检验的那个变量，其余条件都要固定：数据划分、随机种子、训练轮数、超参数搜索预算、评价指标。否则 arm 之间的差异无法归因。

| arm | 相对 baseline 改了什么 | 能回答的问题 |
| --- | --- | --- |
| baseline | — | 参照水平 |
| color_jitter | 增加颜色抖动 | 颜色抖动在其余设置不变时有没有帮助 |
| no_flip | 去掉水平翻转 | 水平翻转本身贡献多少 |

**这里要补一句常被说绝对的话。** 一次只改一个变量（单因素实验）能隔离该因素在固定基线下的效果，但它测不到因素之间的交互，样本效率也不高。如果“颜色抖动是否有效”取决于是否同时用了 AutoAugment，单变量对比就会给出片面结论。多因素设计（因子实验）同时改变几个因素，才能估计主效应和交互；代价是每组样本更少、分析更复杂。选择哪种，取决于你要回答的问题，而不是一句“必须一次只改一个”。

## 三、临床与 A/B 测试里的 arm

同一个词在别的领域也出现：临床试验把随机分组的治疗组叫 treatment arm，对照组叫 control arm；在线 A/B 测试更常说 variant 或 bucket。共同点是随机分配、事先定义、可比较。

arm 越多，比较次数越多，假阳性风险越高。三组两两比较有三次机会，五组有十次。要么预先指定主要比较，要么做多重比较校正，否则“显著”会变多。

## 四、容易混淆的地方

| 说法 | 实际含义 | 常见误读 |
| --- | --- | --- |
| arm | 一个可比较的分支 | ARM 芯片架构 |
| arm 的数量 | 选项数或实验组数 | 样本量 |
| baseline arm | 对照条件 | “没有模型”或“空跑” |
| 多 arm 实验 | 多组同时比较 | 不用校正就能挑最好的 |

## 五、一句话

arm 就是一个可以拿来比较的分支。判断它是否成立，只需问三件事：它和谁比、只差哪一个因素、每组样本够不够。

## 证据边界

- 本页只解释术语与常见用法，不展开 bandit 的 regret 界证明，也不评估具体算法优劣。
- 实验设计部分给的是通用原则；功效分析与样本量要按具体任务、效应大小和方差计算。
