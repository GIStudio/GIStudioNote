## 目标概述

采用可持续的消费和生产模式。

正式目标与指标见[联合国全球指标框架](https://unstats.un.org/sdgs/indicators/indicators-list/)；下面列出相关方向和数据入口。

## 核心下游任务

### 相关监测方向

- 粮食损失与浪费率统计
- 材料利用效率测算
- 电子废弃物产生量监测
- 回收利用率统计
- 化石燃料补贴统计

### AI/机器学习任务

- 废弃物分类与识别
- 产品生命周期碳排放核算
- 供应链可持续性评估
- 非法倾倒检测

## 全球公开数据集

| 数据集名称 | 覆盖范围 | 核心数据维度 | 获取链接 |
| ---------- | -------- | ------------ | -------- |
| 联合国 SDG 全球指标数据库 | 按国家、指标及年度而异 | 可查询目标 12 的可用指标系列；缺失值和各系列口径需单独检查 | [UN SDG Data Portal](https://unstats.un.org/sdgs/dataportal) |
| FAO 食物损失与浪费数据库 | 按来源研究的地点和年份而异 | 汇集公开研究中的食物损失与浪费估计 | [FAO 数据库说明](https://www.fao.org/platform-food-loss-waste/flw-data/background/en) |
| 全球电子废弃物监测报告 | 按报告版本而异 | 电子废弃物产生和管理的统计估计 | [Global E-waste Monitor](https://globalewaste.org/) |

SDG 12.3 的粮食损失指标覆盖收获至零售前阶段，由 FAO 负责；食物浪费指标涵盖零售及消费环节，由 UNEP 负责，两者不能作为同一统计口径。参见 [FAO 方法说明](https://www.fao.org/platform-food-loss-waste/food-loss/food-loss-measurement/en/)。

## 部分具体目标（简述）

下列日期是原定目标期限，不表示目标已如期实现。

- **落实可持续消费框架**：落实可持续消费和生产十年方案框架。
- **实现自然资源可持续管理**：到 2030 年，实现自然资源的可持续管理和高效利用。
- **减少粮食浪费**：到 2030 年，将零售和消费环节的全球人均粮食浪费减半。
- **化学品和环境管理**：到 2020 年，实现化学品和所有废物在整个生命周期内的环保管理。
- **减少废物产生**：到 2030 年，通过预防、减排、回收和再利用，大幅减少废物产生。
- **鼓励可持续商业实践**：鼓励企业采取可持续的商业实践。
- **促进可持续采购**：促进可持续的公共采购做法。
